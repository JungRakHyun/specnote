전자제품은 두 세대만 지나도 중고가가 반 토막 이하로 떨어지는 것이 상식입니다. 그런데 2026년 11월 현재 단종된 지 수년이 지난 **NVIDIA GeForce RTX 3090**은 국내 중고 시장에서 여전히 **110만~160만 원대**를 단단히 방어하고 있습니다.

게이머들이 사 가는 게 아닙니다. 개인 PC에서 AI를 돌리는 [로컬 LLM(Ollama·LM Studio)](/posts/2026-local-llm-ollama-setup-guide/) 열풍 때문입니다. **왜 게이밍 기준으로는 구형인 3090이 AI 추론에서는 최신 중급기를 압도하고 4090과도 큰 차이가 나지 않는지** 아키텍처 원리부터 풀고, 중고 불량 판별법과 전기료·발열을 낮추는 `nvidia-smi` 실전 세팅까지 정리했습니다.

## 1. 원리부터 이해하기: 왜 게이밍 스펙과 LLM 스펙은 다를까?

로컬 LLM이 질문에 답하는 과정은 두 단계로 나뉩니다.
1. **Prefill(프롬프트 읽기):** 내가 입력한 긴 텍스트를 GPU 코어가 병렬로 한 번에 처리하는 단계 — <strong>GPU 연산력(Compute-bound)</strong>에 좌우됩니다.
2. **Decode(답변 글자 생성):** AI가 단어(토큰)를 1개씩 뽑아내는 단계 — 토큰 1개를 만들 때마다 모델 가중치 전체를 VRAM에서 읽어와야 하므로 <strong>메모리 대역폭(Memory-bound)</strong>이 속도의 대부분을 결정합니다.

게이밍용 최신 중급기(RTX 5060/5070 계열)는 아키텍처와 AI 프레임 생성이 좋아졌지만, **VRAM이 12~16GB이고 메모리 버스 폭이 좁아 대역폭이 300~600 GB/s 수준**입니다. 반면 RTX 3090은 384비트 광폭 버스에 GDDR6X를 얹어 **24GB VRAM과 936 GB/s 대역폭**을 갖췄습니다. 32B 모델(약 20GB)을 통째로 올리고 초당 30토큰 이상으로 뽑아내는 최소 입장권이 바로 RTX 3090인 셈입니다.

## 2. RTX 3090 vs RTX 4090 vs RTX 5090 vs 맥북 프로 정밀 비교

| 비교 항목 | RTX 3090 (중고) | RTX 4090 (중고·리퍼) | RTX 5090 (신품) | 맥북 프로 M5 Pro (36GB+) |
| :--- | :--- | :--- | :--- | :--- |
| **VRAM / 통합 메모리** | **24GB (GDDR6X)** | 24GB (GDDR6X) | **32GB (GDDR7)** | 36GB ~ 64GB (UMA) |
| **메모리 대역폭** | **936 GB/s** | 1,008 GB/s (+7.7%) | **1,792 GB/s** (+91%) | 최대 307 GB/s |
| **32B(Q4) 예상 생성 속도** | **약 30~35 tok/s** | 약 35~40 tok/s | 약 60 tok/s 이상 | 약 12 tok/s |
| **긴 프롬프트 읽기(Prefill)** | 빠름 (CUDA 가속) | 매우 빠름 (FP8 가속) | 최고속 (5세대 Tensor FP4) | 상대적으로 느림 |
| **소비전력 / 권장 파워** | 350W / **850W+** | 450W / 850~1000W | 575W / **1000W+ 필수** | **30~60W** (무소음·휴대) |
| **2026년 11월 국내 시세** | **중고 110~160만 원대** | 중고 고가 형성 | 초고가 신품 | 349~429만 원~ (신품 보증) |

표에서 가장 눈에 띄는 숫자 두 가지가 RTX 3090의 인기를 설명합니다.
- **첫째, 4090과 3090은 VRAM이 똑같이 24GB이고 대역폭 차이가 겨우 7.7%입니다.** 순수 토큰 생성 효율(가격 대비 초당 토큰 수)에서는 3090이 압도적으로 유리합니다.
- **둘째, 2장을 묶으면 250~300만 원대로 ‘48GB CUDA VRAM’ 홈랩이 됩니다.** 70B 대형 모델(약 43GB)을 CUDA 가속으로 돌릴 수 있는 워크스테이션 GPU가 수천만 원대라는 점을 감안하면 대체재가 거의 없습니다.

## 3. 중고 RTX 3090 구매 전 4단계 불량 판별 체크리스트

RTX 3090은 2021~2022년 채굴 붐을 거친 매물이 섞여 있고, **기판 뒷면(백플레이트 쪽)에도 GDDR6X 메모리 칩이 절반 붙어 있어** 후면 발열 노화에 취약합니다. 직거래·중고 구매 전 아래 4가지를 반드시 확인하세요.

1. **HWInfo64 메모리 정션 온도 캡처 요구 (가장 중요):** [HWiNFO64](https://www.hwinfo.com/) 센서 창을 켠 채 3DMark나 Ollama 연속 추론을 5분 이상 돌렸을 때 **`GPU Memory Junction Temperature`가 100~110℃까지 치솟는다면 써멀패드가 경화된 매물**입니다. 정상 범위는 80~94℃ 이하이며, 100℃ 이상이면 구매 후 분해해 써멀패드를 직접 교체(부품비 3~5만 원)해야 합니다.
2. **팬 베어링 갈림 & 히트싱크 백화 확인:** 쿨링팬을 70% 이상 올렸을 때 쇠 갈림 소리나 저속 떨림이 없는지, 알루미늄 방열핀에 하얀 산화(부식) 흔적이 없는지 육안 확인하세요.
3. **정격 850W+ 파워 & 독립 8핀 케이블 배선:** RTX 3090은 순간 전력 스파이크가 큽니다. **정격 850W 이상(80PLUS Gold)** 파워에서 Y자 분기 케이블 하나에 두 포트를 꽂지 말고, 파워에서 나오는 독립 PCIe 8핀 케이블을 각각 따로 연결해야 부하 시 재부팅을 막습니다.
4. **케이스 길이(320~340mm) 및 그래픽카드 지지대:** 1.5~2kg 무게로 PCIe 슬롯과 기판이 휘어 냉납 불량이 나기 쉬우므로 만 원짜리 지지대는 필수입니다.

## 4. 전기료·발열·팬 소음을 확 줄이는 `nvidia-smi` 전력 제한 세팅

로컬 LLM 추론(Decode)은 게이밍과 달리 GPU 코어를 100% 풀클럭으로 태우지 않고 **메모리 대역폭을 읽는 비중**이 큽니다. 그래서 기본 350W 전력 제한을 **260W~280W**로 낮춰도 토큰 생성 속도 손실은 2~4% 수준에 불과하지만, 실내 발열과 메모리 온도·팬 소음은 확연히 줄어듭니다.

Windows 관리자 권한 PowerShell 또는 Linux 터미널에서 아래 명령어 한 줄로 바로 테스트해 볼 수 있습니다.

```bash
# 현재 소비전력 및 허용 전력 제한 범위 확인
nvidia-smi -q -d POWER

# GPU 0번 전력 상한을 280W로 제한 (재부팅 시 기본값 복원)
nvidia-smi -i 0 -pl 280
```
