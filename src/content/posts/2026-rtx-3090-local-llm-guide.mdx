일반적으로 그래픽카드는 두 세대만 지나도 중고가가 반 토막 이하로 떨어집니다. 그런데 2026년 11월 현재 단종된 지 수년이 지난 **NVIDIA GeForce RTX 3090**은 국내 중고 시장에서 여전히 **110만~160만 원대**를 유지하고 있습니다.

게이머 수요가 아니라 **로컬 LLM(Ollama, LM Studio, vLLM) 구축 수요** 때문입니다. 최신 중급기 대신 왜 구형 3090이 AI 홈랩의 기준점이 됐는지, 중고 구매 시 불량을 거르는 점검 순서와 전기료·발열을 낮추는 `nvidia-smi` 실전 세팅까지 정리했습니다.

## 1. RTX 3090 vs RTX 4090 vs RTX 5090 로컬 LLM 스펙 비교

로컬 AI 추론 속도는 GPU 클럭보다 <strong>VRAM 용량(올릴 수 있는 모델 크기)</strong>과 <strong>메모리 대역폭(초당 토큰 생성 속도)</strong>이 결정합니다.

| 항목 | RTX 3090 (중고) | RTX 4090 (중고·리퍼) | RTX 5090 (신품) |
| :--- | :--- | :--- | :--- |
| **VRAM 용량** | **24GB (GDDR6X)** | 24GB (GDDR6X) | **32GB (GDDR7)** |
| **메모리 대역폭** | **936 GB/s** | 1,008 GB/s (+7.7%) | **1,792 GB/s** (+91%) |
| **예상 32B(Q4) 추론 속도** | 약 30~35 tok/s | 약 35~40 tok/s | 약 60 tok/s 이상 |
| **Tensor 세대 / 특화** | 3세대 Tensor (FP16/BF16) | 4세대 Tensor (FP8) | **5세대 Tensor (FP4 네이티브)** |
| **소비전력 (TDP / 권장 파워)** | 350W / **850W+** | 450W / 850~1000W | 575W / **1000W+ 필수** |
| **2026년 11월 국내 시세** | **중고 110~160만 원대** | 중고 고가 형성 | 초고가 신품 |

표에서 핵심은 **RTX 3090(936 GB/s)과 RTX 4090(1,008 GB/s)의 VRAM이 똑같이 24GB이고 대역폭 차이는 8% 미만**이라는 점입니다. 순수 LLM 토큰 생성 효율만 따지면 3090의 가격 대비 성능이 가장 높고, 2장을 묶어 <strong>48GB VRAM(70B 모델 구동)</strong>을 250~300만 원대에 만들 수 있는 유일한 소비자용 CUDA 카드라는 점이 시세를 떠받치고 있습니다.

## 2. 중고 RTX 3090 구매 전 4단계 불량 판별 체크리스트

RTX 3090은 2021~2022년 채굴 붐을 겪은 매물이 섞여 있고, **기판 뒷면(백플레이트 쪽)에도 GDDR6X 메모리가 장착**돼 있어 발열 노화에 취약합니다. 직거래·중고 구매 전 아래 4가지를 확인하세요.

1. **HWInfo64로 메모리 정션 온도 확인 (필수):** 판매자에게 [HWInfo64](https://www.hwinfo.com/) 센서 창을 켠 상태에서 3DMark나 Ollama 연속 추론을 5분 돌린 캡처를 요청하세요. **`GPU Memory Junction Temperature`가 100~110℃까지 치솟는다면 써멀패드가 경화된 상태**라 구매 후 직접 분해·교체 작업(비용 3~5만 원)이 필요합니다. 정상 범위는 80~94℃ 이하입니다.
2. **팬 베어링 소음 및 백플레이트 변색:** 쿨링팬을 70% 이상 올렸을 때 쇠 갈리는 소리나 저속 떨림이 있는지, 히트싱크 핀에 하얀 백화(부식) 흔적이 없는지 확인하세요.
3. **파워서플라이 & 8핀 케이블 분리 배선:** RTX 3090은 순간 전력 스파이크가 큽니다. **정격 850W 이상(80PLUS Gold)** 파워에서 Y자 분기 케이블 하나에 두 포트를 꽂지 말고, 파워에서 나오는 독립 PCIe 8핀 케이블을 각각 따로 연결해야 셧다운을 막을 수 있습니다.
4. **케이스 길이(320~340mm) 및 지지대:** 3090 비레퍼 모델은 무게가 1.5~2kg에 육박해 지지대 없이 꽂아두면 PCIe 슬롯이나 기판이 휘어 냉납 불량이 발생합니다.

## 3. 구매 후 발열·전기료 줄이는 실전 팁 (`nvidia-smi` 전력 제한)

로컬 LLM 추론은 게이밍과 달리 GPU 코어를 100% 풀로 태우기보다 **메모리 대역폭을 읽는 작업**이 주를 이룹니다. 따라서 기본 350W 전력 제한을 **260W~280W**로 낮춰도 토큰 생성 속도 손실은 2~4% 수준에 불과한 반면, 팬 소음과 실내 발열·메모리 온도는 눈에 띄게 떨어집니다.

Windows 관리자 권한 PowerShell 또는 Linux 터미널에서 아래 명령어 한 줄로 바로 적용할 수 있습니다.

```bash
# 현재 소비전력 및 허용 범위 확인
nvidia-smi -q -d POWER

# GPU 0번 전력 상한을 280W로 제한 (재부팅 시 기본값 복원)
nvidia-smi -i 0 -pl 280
```

  1) AS가 끝난 150만 원짜리 중고 부품의 고장 리스크를 감당하기 싫을 때, 2) 원룸·거실처럼 여름철 300W+ 열기와 팬 소음이 치명적인 환경일 때, 3) 기존 PC 파워·케이스·메인보드까지 통째로 갈아야 해서 총비용이 250만 원을 넘길 때는 중고 3090의 가성비가 무너집니다.

## 4. 중고 리스크가 부담스러울 때의 현실적인 신품 대안

- **데스크톱 신품 최고 성능이 필요할 때:** 32GB VRAM + 1,792 GB/s + FP4 가속을 지원하는 **RTX 5090** (단, 예산과 1000W+ 파워·대형 케이스 필수)
- **저전력·저소음·공식 신품 보증이 우선일 때:** 307 GB/s 통합 메모리 대역폭과 공식 AS를 갖춘 **MacBook Pro 16 M5 Pro(36GB+)** 구성. 토큰 속도는 3090의 약 1/3 수준이지만 소비전력이 1/5 이하이고 휴대가 가능합니다.
