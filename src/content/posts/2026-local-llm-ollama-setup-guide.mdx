매달 나가는 AI 구독료가 부담스럽거나, 회사 기밀 코드·내부 문서를 외부 서버로 보내기 찝찝해 **내 PC에서 직접 AI를 돌리는 ‘로컬 LLM’** 구축 수요가 2026년 들어 폭발적으로 늘었습니다.

예전에는 파이썬 환경과 CUDA 드라이버를 며칠씩 씨름해야 했지만, 지금은 **Ollama**나 **LM Studio**를 설치하면 5분 만에 내 컴퓨터를 개인 AI 서버로 만들 수 있습니다. 이 글에서는 **내 하드웨어(VRAM)에 딱 맞는 모델 선택표, 설치 방법, PC vs 맥북 하드웨어 구성 전략**을 한 번에 정리합니다.

## 1. 로컬 LLM의 핵심 원리: 왜 VRAM과 대역폭이 전부일까?

로컬 LLM 실행에서 가장 흔한 오해는 “CPU 코어가 많거나 일반 램(RAM)이 64GB면 빠르겠지”라고 생각하는 것입니다.

- **VRAM 용량 = 올릴 수 있는 모델의 지능(크기):** 모델 가중치(보통 4비트 양자화 `Q4_K_M`)와 대화 문맥(KV 캐시)이 GPU VRAM 안에 통째로 올라가야 제 속도가 나옵니다.
- **메모리 대역폭(GB/s) = 답변이 타이핑되는 속도(TPS):** AI가 단어(토큰) 하나를 뽑을 때마다 VRAM 전체를 읽어 들이므로, 메모리 대역폭이 넓을수록 답변 속도가 빠릅니다.

## 2. VRAM 사양별 2026 추천 오픈웨이트 모델 & 실행 명령어

2026년 로컬 LLM 생태계는 한국어·코딩 최강 **Qwen3 / Qwen3.8**, 추론 특화 **DeepSeek-R1 Distill**, 범용 **Llama·Gemma** 3강 구도로 정리됩니다.

| 내 VRAM 사양 | 대표 하드웨어 예시 | 추천 모델 (Q4 양자화 기준) | Ollama 실행 명령어 |
| :--- | :--- | :--- | :--- |
| **8 GB** | RTX 3060 / 4060 | **7B ~ 8B 급** (가벼운 요약·번역·보조) | `ollama run qwen3:8b` / `deepseek-r1:7b` |
| **12 ~ 16 GB** | RTX 4060 Ti 16GB / 맥북 24GB | **12B ~ 14B 급** (실무 문서·코딩 입문) | `ollama run deepseek-r1:14b` / `gemma4:12b` |
| **24 GB (황금라인)** | **RTX 3090 중고** / 4090 / 맥북 32GB+ | **27B ~ 32B 급** (범용·코딩·추론 실전급) | `ollama run qwen3.8:27b` / `deepseek-r1:32b` |
| **48 GB 이상** | RTX 3090 듀얼 / 맥 스튜디오 64GB+ | **70B 대형 모델** (고난도 추론·장문) | `ollama run llama3.1:70b` |

## 3. 소프트웨어 2대장 비교: Ollama vs LM Studio

| 비교 항목 | **[Ollama](https://ollama.com/download)** | **[LM Studio](https://lmstudio.ai/)** |
| :--- | :--- | :--- |
| **인터페이스** | 터미널(CLI) + 백그라운드 데몬 | **직관적인 데스크탑 GUI 앱** |
| **장점** | 가벼움, `localhost:11434` OpenAI 호환 API 즉시 제공 | 모델 검색·VRAM 오프로드·초당 토큰(TPS) 시각화 |
| **추천 조합** | VS Code / Cursor / Open WebUI 연동 개발자 | 명령어 없이 바로 채팅·테스트하고 싶은 입문자 |

- **ChatGPT처럼 웹 화면으로 쓰고 싶다면?** [Ollama](https://ollama.com/download)를 켠 상태에서 Docker로 [Open WebUI](https://openwebui.com/)를 띄우면 사내·집안 공유기 안의 모든 기기에서 스마트폰으로도 내 로컬 AI에 접속할 수 있습니다.

## 4. 예산별 로컬 LLM 하드웨어 구성 3가지

1. **최고 가성비 데스크탑 (예산 150~220만 원대):**
   - **중고 RTX 3090 (24GB VRAM, 약 110~160만 원)** + 850W 이상 파워서플라이 구성
   - 936GB/s의 초고속 대역폭과 CUDA 호환성 덕분에 27B~32B 모델을 초당 수십 토큰으로 쾌적하게 돌릴 수 있습니다. 자세한 시세와 중고 구매 팁은 [RTX 3090이 2026년에 다시 핫해진 이유](/posts/2026-rtx-3090-local-llm-guide/) 글에서 자세히 다루었습니다.
2. **저전력·휴대성 올인원 (예산 250~400만 원대):**
   - **애플 실리콘 맥북 프로 M4 Pro / M5 Pro (통합 메모리 24GB~36GB+)**
   - 데스크탑의 350W 발열·소음 없이 카페에서도 로컬 AI와 코딩을 동시에 돌릴 수 있습니다. 칩셋별 대역폭 차이는 [2026 AI 작업용 맥북 프로 구매 가이드](/posts/2026-macbook-pro-ai-buying-guide/)를 참고하세요.
3. **70B 대형 모델 홈랩 (예산 300~500만 원대):**
   - **RTX 3090 듀얼 (48GB VRAM)** 또는 **맥 스튜디오 64GB~128GB 통합 메모리**

## 5. 설치 후 바로 따라 하는 3분 시작 체크리스트

1. **[Ollama 공식 다운로드 페이지](https://ollama.com/download)**(또는 GUI를 원하면 **[LM Studio 공식 다운로드](https://lmstudio.ai/)**)에서 Windows/macOS용 설치 파일을 받아 설치합니다.
2. 터미널을 열고 내 VRAM에 맞는 모델 명령어 한 줄을 입력합니다. (예: `ollama run qwen3:8b` 또는 `ollama run qwen3.8:27b`)
3. AI 코딩 에디터([Cursor·Claude Code 비교](/posts/2026-ai-coding-tools-guide/))나 로컬 자동화 스크립트에서 베이스 URL을 `http://localhost:11434/v1`로 연결하면 API 요금 0원으로 바로 활용할 수 있습니다.
