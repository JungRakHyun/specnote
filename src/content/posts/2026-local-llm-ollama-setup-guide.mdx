매달 나가는 AI 구독료가 부담스럽거나, 회사 기밀 문서·개인 코드를 외부 클라우드 서버에 올리기 꺼려진다면 <strong>내 PC 안에서 직접 AI를 실행하는 로컬 LLM(온디바이스 AI)</strong>이 가장 확실한 해답입니다.

2026년 11월 현재 로컬 AI 생태계의 사실상 표준 도구로 자리 잡은 **Ollama**를 사용하면 복잡한 파이썬 환경 설정 없이 단 3분 만에 내 컴퓨터에 무료 AI 어시스턴트를 구축할 수 있습니다. 이 가이드에서는 **운영체제별 설치법, PC 메모리(RAM/VRAM) 사양별 추천 모델, ChatGPT 스타일 웹 UI 연동, 로컬 AI용 하드웨어 선택 기준**까지 실전 중심으로 정리합니다.

## 1. Ollama가 2026년 로컬 LLM 표준이 된 이유

과거 로컬 AI를 실행하려면 CUDA 드라이버 버전 충돌을 해결하고 수동으로 모델 포맷(GGUF)을 변환해야 했습니다. 반면 **Ollama**는 모델 다운로드·양자화 관리·GPU 가속·로컬 API 서버(`http://localhost:11434`)를 하나의 경량 패키지로 통합했습니다.

- **네이티브 데스크톱 앱 + CLI 동시 지원:** 터미널 명령어(`ollama run`)뿐 아니라 Windows·macOS용 기본 데스크톱 채팅 UI를 제공해 파일·이미지 드래그 앤 드롭 분석까지 바로 활용할 수 있습니다.
- **자동 하드웨어 가속:** NVIDIA(CUDA), AMD(ROCm/Vulkan), Apple Silicon(Metal)을 별도 설정 없이 자동 감지해 최대한의 토큰 생성 속도를 끌어냅니다.
- **완벽한 프라이버시와 비용 0원:** 모델 파일만 내려받으면 비행기 안이나 사내 폐쇄망처럼 인터넷이 없는 환경에서도 토큰 과금 없이 무제한 실행됩니다.

## 2. 운영체제별 Ollama 설치 및 3분 첫 실행

공식 다운로드 페이지(`ollama.com/download`)에서 OS에 맞는 설치 파일을 받거나 터미널 명령어로 바로 설치할 수 있습니다.

### ① Windows · macOS 설치 (가장 간편)
1. **Windows:** `OllamaSetup.exe`를 내려받아 실행합니다. 관리자 권한 없이 사용자 계정에 설치되며 NVIDIA·AMD GPU 가속을 자동 구성합니다.
2. **macOS:** 공식 설치 앱을 Applications 폴더로 옮기거나 터미널에서 `brew install ollama` 명령으로 설치합니다.

### ② Linux 설치
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### ③ 설치 확인 및 첫 모델 실행
설치가 끝나면 터미널(PowerShell 또는 macOS 터미널)을 열고 아래 명령어를 순서대로 입력합니다.

```bash
# 설치 버전 확인
ollama --version

# 한국어 성능이 뛰어난 Qwen3 8B 모델 다운로드 및 대화 시작
ollama run qwen3:8b

# 설치된 모델 목록 확인 및 불필요한 모델 삭제
ollama list
ollama rm qwen3:8b
```

<Callout type="tip" title="터미널이 낯설다면? 데스크톱 앱과 Open WebUI 활용">
  Ollama를 실행하면 작업 표시줄이나 메뉴 막대에 아이콘이 뜨며 기본 채팅 창에서 바로 대화를 시작할 수 있습니다. 만약 ChatGPT와 거의 동일한 대화 기록 관리·문서 RAG·한국어 메뉴 환경이 필요하다면 Docker로 <strong>Open WebUI</strong>를 띄워 <code>http://localhost:3000</code>에서 로컬 Ollama 서버와 연동하는 구성을 추천합니다.
</Callout>

## 3. 2026년 사양별 추천 로컬 LLM 비교표 (Ollama 공식 라이브러리 기준)

로컬 LLM은 기본 4비트 양자화(Q4) 모델 크기 외에 **대화 문맥(KV 캐시)을 담을 여유 메모리 20~30%**가 추가로 필요합니다. 2026년 11월 기준 `ollama.com/library`에서 바로 실행할 수 있는 핵심 모델 5종과 권장 메모리를 비교했습니다.

| 모델명 (실행 명령) | 개발사 | 다운로드 크기(Q4 기준) | 권장 RAM / VRAM | 핵심 강점 및 추천 용도 |
| :--- | :--- | :--- | :--- | :--- |
| **`exaone3.5:7.8b`** | LG AI연구원 | 약 4.8GB | **12GB ~ 16GB** | 자연스러운 한국어·영어 바이링궐, 문서 요약·보고서 작성 |
| **`qwen3:8b` / `14b`** | Alibaba | 약 5~9GB | **12GB ~ 24GB** | 한국어·코딩·추론(Thinking) 균형 최강, 올라운더 표준 |
| **`gemma3:12b`** | Google DeepMind | 약 8.1GB | **16GB** | 이미지 인식(Vision) 멀티모달 지원, 깔끔한 지시 이행 |
| **`deepseek-r1:14b` / `32b`** | DeepSeek | 약 9GB / 20GB | **16GB ~ 24GB+** | 단계별 사고 과정(CoT) 기반 수학·알고리즘·복잡한 디버깅 |
| **`llama3.3:70b`** | Meta | 약 43GB | **48GB ~ 64GB+** | 다국어 지원·긴 문맥·RAG 구축 등 클라우드급 대형 모델 |

### 내 PC 메모리별 가장 실패 없는 첫 모델 조합
1. **RAM 8GB ~ 12GB (일반 사무용 노트북):** `exaone3.5:2.4b`(약 1.6GB) 또는 `gemma3:4b`(약 3.3GB)로 가볍게 시작하세요. 요약·번역·간단한 이메일 초안 작성에 충분합니다.
2. **RAM / VRAM 16GB (개발자 표준 환경):** 한국어 문서 작업은 `exaone3.5:7.8b`, 범용 코딩·질의응답은 `qwen3:8b`, 스크린샷·문서 이미지 해석은 `gemma3:12b` 조합이 가장 쾌적합니다.
3. **VRAM 24GB 또는 통합 메모리 32GB+ (로컬 AI 스윗스팟):** `deepseek-r1:32b`나 `qwen3:32b`를 무리 없이 올릴 수 있어 로컬 환경에서도 수준 높은 추론과 코드 리뷰가 가능합니다.

<Callout type="warning" title="로컬 LLM 성능의 핵심 병목: CPU가 아니라 메모리 용량과 대역폭">
  모델 가중치가 GPU VRAM에 다 들어가지 못해 일반 시스템 RAM으로 넘어가면(오프로드) 답변 속도가 급격히 느려집니다. 로컬 AI를 본격적으로 돌릴 계획이라면 CPU 등급보다 <strong>그래픽카드 VRAM 용량</strong> 또는 애플 실리콘의 <strong>통합 메모리(RAM) 용량과 대역폭</strong>을 최우선으로 보셔야 합니다. 자세한 맥북 스펙 비교는 [2026 AI 작업용 맥북 프로 구매 가이드](/posts/2026-macbook-pro-ai-buying-guide/)에서 확인할 수 있습니다.
</Callout>

## 4. 개발자·파워유저 실전 활용법 (코딩 툴 연동)

Ollama는 단순히 대화용 챗봇에 그치지 않고 로컬 개발 파이프라인의 엔진으로 쓸 수 있습니다.

- **로컬 AI 코딩 어시스턴트 연동:** `ollama launch` 명령어나 OpenAI 호환 엔드포인트(`http://localhost:11434/v1`)를 활용해 VS Code 확장 프로그램(Continue 등) 및 터미널 에이전트와 연결할 수 있습니다. 유료 AI 코딩 도구와의 장단점 비교는 [2026 AI 코딩 툴 완전 비교](/posts/2026-ai-coding-tools-guide/)를 참고해 보세요.
- **이미지·문서 파이프라인 자동화:** `ollama run gemma3:12b "이 영수증의 날짜와 합계 금액을 JSON으로 추출해줘" ./receipt.png`처럼 명령줄에서 바로 멀티모달 분석을 스크립트화할 수 있습니다.
- **클라우드 구독과 하이브리드 운영:** 보안이 민감한 사내 코드·개인 메모는 Ollama로 처리하고, 최신 웹 검색이나 초고난도 설계만 클라우드 모델에 맡기면 전체 AI 비용을 크게 낮출 수 있습니다. 주요 유료 요금제 비교는 [2026 AI 유료 구독 총정리](/posts/2026-ai-subscription-comparison/)에서 확인해 보세요.

## 6. 시작 전 최종 체크리스트

1. **디스크 여유 공간 확인:** 모델 1개당 보통 4GB~20GB를 차지하므로 SSD 여유 공간을 최소 30GB 이상 확보한 뒤 테스트하세요.
2. **한국어 우선이라면 EXAONE 3.5 또는 Qwen3부터:** 영어 중심 모델보다 한국어 토크나이저 효율이 높아 같은 파라미터 크기에서도 답변 품질과 속도가 훨씬 뛰어납니다.
3. **공식 라이브러리로 최신 버전 유지:** Ollama는 모델 업데이트가 매우 빠르므로 주기적으로 `ollama pull <모델명>`을 실행해 최신 개선 버전을 반영하는 것을 권장합니다.
