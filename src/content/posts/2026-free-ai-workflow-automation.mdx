“AI로 하루 2시간 아끼기” 같은 글을 보면 대부분 ChatGPT 창을 열고 매번 문장을 새로 입력하는 수동 프롬프트만 나열합니다. 하지만 **매번 창을 열고 조건을 다시 치는 순간 이미 5~10분이 새어 나갑니다.**

진짜 시간이 줄어드는 지점은 **① 매번 똑같은 출력 형식을 고정(템플릿화)하고 ② 구글 시트·단축어·무료 자동화 툴로 클릭 횟수를 1~2번으로 줄일 때**입니다. 2026년 11월 기준 월 0원으로 바로 세팅할 수 있는 5가지 실전 루틴을 실제 입력·출력 예시와 코드까지 포함해 정리했습니다.

## 1. 회의 녹취록 → 담당자별 액션 테이블 자동 변환

무료 음성 기록 도구(네이버 클로바노트 무료 시간, Google Meet 자막 등)에서 뽑은 원문은 말버릇과 잡담이 섞여 바로 공유하기 어렵습니다. 핵심은 **출력 컬럼을 못 박아두는 것**입니다.

### 실제 입력 예시 (원본 메모)
```text
김대리: 결제 페이지 로딩이 3초 넘게 걸리는데 이미지 용량 때문인 듯요. 목요일까지 WebP로 바꿔볼게요.
박과장: 좋아요. 근데 금요일 마케팅 배너 교체 건은 디자인팀 시안이 아직 안 와서 보류해야 할 것 같습니다.
이팀장: 그럼 배너 건은 다음 주 화요일에 다시 보고, 김대리님은 목요일 오후 3시에 테스트 결과 공유해 주세요.
```

### 고정 프롬프트 (브라우저 북마크·텍스트 대치에 저장)
```text
아래 회의 메모에서 잡담을 제거하고 다음 3개 블록만 출력해 줘. 없는 정보는 '미정'으로 적어.
1) 확정 사항 (불릿 최대 3줄)
2) 액션 아이템 표 (컬럼: 담당자 | 할 일 | 마감일 | 상태)
3) 보류/리스크 이슈 (1줄)
```

### 실제 출력 결과 (그대로 슬랙·노션 붙여넣기 가능)
| 담당자 | 할 일 | 마감일 | 상태 |
| :--- | :--- | :--- | :--- |
| 김대리 | 결제 페이지 이미지 WebP 변환 및 테스트 결과 공유 | 목요일 15:00 | 진행 예정 |
| 박과장 | 마케팅 배너 교체 건 디자인팀 시안 대기 | 다음 주 화요일 재논의 | 보류 |

## 2. 구글 시트 문의 내역 → 카테고리·우선순위 자동 분류 (Apps Script)

카톡·이메일·구글 폼으로 들어오는 고객 문의나 견적 요청을 수작업으로 분류하지 말고, **구글 시트에 행이 쌓이면 자동으로 카테고리·긴급도를 채우는 함수**를 붙여두세요. [Google AI Studio](https://aistudio.google.com/)의 무료 Gemini API 키를 발급받아 `확장 프로그램 → Apps Script`에 아래 함수를 넣으면 시트 셀에서 `=CLASSIFY_INQUIRY(A2)`처럼 엑셀 함수 쓰듯 호출할 수 있습니다.

```javascript
function CLASSIFY_INQUIRY(text) {
  if (!text) return "";
  const apiKey = PropertiesService.getScriptProperties().getProperty("GEMINI_API_KEY");
  const url = "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=" + apiKey;
  const payload = {
    contents: [{
      parts: [{
        text: "다음 문의를 [결제/환불, 기술오류, 제휴문의, 기타] 중 하나와 [긴급/보통/낮음]으로만 답해. 형식: 카테고리 | 긴급도\n문의: " + text
      }]
    }]
  };
  const res = UrlFetchApp.fetch(url, {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify(payload)
  });
  const json = JSON.parse(res.getContentText());
  return json.candidates[0].content.parts[0].text.trim();
}
```

- **주의할 점:** API 키를 코드 안에 직접 적지 말고 `프로젝트 설정 → 스크립트 속성`에 `GEMINI_API_KEY`로 저장하세요. 시트를 팀원과 공유해도 키가 노출되지 않습니다.

## 3. 까다로운 거절·일정 연기 메일 → 2버전 10초 초안

이메일 작성에서 시간을 잡아먹는 건 문장력이 아니라 **수신자 직급과 관계에 맞는 톤 조절**입니다. “일정 연기 메일 써줘”처럼 막연하게 묻지 말고, **사실 3줄 + 수신자 성향 + 금지 표현**을 같이 던지세요.

```text
[사실] 1) 납품 일정 3일 연기 필요(11/28 → 12/1) 2) 사유: 결제 PG사 예외 테스트 보완 3) 보상: 검수 리포트 추가 제공
[수신자] 외부 클라이언트 대기업 담당자 (격식 중시)
[요청] 지나치게 저자세이거나 변명처럼 보이지 않게 '간결형(5줄 이내)'과 '정중형' 2가지 이메일 초안을 써줘.
[금지] "심심한 사과", "최선을 다하겠습니다" 같은 상투적 표현 제외.
```

macOS·아이폰 사용자라면 Apple 단축어(Shortcuts)에 이 템플릿을 등록해 두고 클립보드 메모만 넘기면 브라우저를 열지 않고도 바로 초안을 받을 수 있습니다.

## 4. 매일 아침 5분 업종 브리핑 → 출처 검증까지 한 번에

일반 챗봇은 최신 뉴스 날짜를 섞거나 없는 기사를 지어내는 경우가 잦습니다. 출처 URL을 강제하는 검색형 AI([Perplexity](https://www.perplexity.ai/) 무료 티어)에 아래 쿼리를 브라우저 북마크로 저장해 두고 아침마다 클릭 한 번으로 실행하세요.

```text
최근 72시간 내 발표된 [내 업종: 예) 국내 이커머스 물류 / 생성형 AI 요금제] 핵심 뉴스 5건만 추려줘.
조건: 1) 언론사·공식 블로그 원문 링크 필수 2) 발행 날짜 표기 3) 실무 영향 1줄 요약. 확인 안 된 루머는 제외해.
```

## 5. 금요일 주간 보고서 → 평일 1줄 로그 자동 합산

금요일 오후 4시에 일주일 기억을 더듬는 대신, 월~금요일 동안 노션·메모장 한 페이지에 `11/24 결제 API 타임아웃 원인 수정 (응답시간 2.4s → 0.6s)`처럼 **결과 수치 1줄씩만 던져둡니다.** 금요일에 이 텍스트만 통째로 복사해 아래 규칙으로 변환하면 3분 만에 보고서가 나옵니다.

- **핵심 규칙:** `금주 완료(수치 포함) / 지연·리스크(원인+대응) / 차주 우선순위 Top 3` 3단 고정 + 원문에 없는 성과는 절대 지어내지 말 것(환각 차단).
