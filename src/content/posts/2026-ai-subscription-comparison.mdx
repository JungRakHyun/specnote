ChatGPT Plus, Claude Pro, Google AI Pro, Perplexity Pro는 모두 표준 요금제가 <strong>월 $20(약 2만 원대 후반)</strong>으로 거의 같습니다. 그런데도 누구는 “Claude가 없으면 일을 못 한다”고 하고, 누구는 “Gemini 하나로 끝냈다”고 말하는 이유는 <strong>각 서비스가 제공하는 ‘세부 모델의 설계 목적’과 ‘주변 작업 도구’가 완전히 다르기 때문</strong>입니다.

2026년 11월 기준 4대 서비스 안에 실제로 어떤 세부 모델이 들어 있는지, **코딩·수학/논리 추론·100만 토큰 장문/멀티모달·웹 리서치·한국어 품질** 5개 축에서 성능이 어떻게 갈리는지, 그리고 **사용자 유형 6가지별로 무엇을 고르는 게 돈값을 하는지** 깊게 비교했습니다.

## 1. 브랜드가 아니라 ‘세부 모델 라인업’부터 구분해야 합니다

같은 월 $20 구독이라도 안에는 **빠른 일상용 경량 모델**과 **시간이 더 걸리지만 깊게 생각하는 추론·플래그십 모델**이 함께 들어 있습니다. 어떤 모델이 어떤 역할을 맡는지 알아야 요금제 비교가 정확해집니다.

| 서비스 | 경량 · 일상 고속 모델 | 주력 실무 모델 | 심층 추론 · 고난도 모델 | 구독에 묶인 핵심 전용 도구 |
| :--- | :--- | :--- | :--- | :--- |
| **ChatGPT (OpenAI)** | GPT-5 계열 고속 모델 | GPT-5.6 / GPT-6 표준 | **GPT-6 추론(Sol·Astra 계열)** | 실시간 음성 대화, 이미지 생성, Python 데이터 분석, 커스텀 GPTs |
| **Claude (Anthropic)** | **Claude Haiku** | **Claude Sonnet 5 계열** | **Claude Opus (4.8/5.5 계열)** | **Claude Code(터미널 에이전트)**, Artifacts 실시간 프리뷰, 프로젝트 |
| **Google AI (Gemini)** | **Gemini Flash** | **Gemini 3.1 Pro / 4 계열** | Gemini Pro 심층 추론(Deep Think) | Gmail·Docs·Sheets 연동, **NotebookLM**, **Flow(Veo 영상)**, Google One |
| **Perplexity Pro** | 자체 빠른 검색(Sonar) | **GPT · Claude · Gemini 선택** | 멀티 모델 + **Deep Research** | 문장별 실시간 웹 출처 인용, 학술·재무 소스 필터 검색 |

여기서 중요한 구조적 차이가 드러납니다.
- **ChatGPT·Claude·Gemini**는 자체 모델을 중심으로 <strong>작업 환경(음성·코드·구글 오피스)</strong>을 묶어 파는 플랫폼입니다.
- **Perplexity**는 모델을 직접 만드는 것보다 <strong>“검색 엔진 + 최신 타사 모델 스위칭 + 자동 출처 검증”</strong>에 특화된 리서치 도구입니다.

## 2. 5대 핵심 역량별 세부 모델 정면 성능 비교

2026년 하반기 주요 공개 벤치마크(SWE-bench, AIME, GPQA)와 실무 체감 기준으로 5가지 핵심 영역에서 각 모델군의 성격을 나누어 보면 차이가 분명해집니다.

| 평가 영역 | 1순위 강세 모델 | 2순위 / 특징 | 실무에서 체감되는 결정적 차이 |
| :--- | :--- | :--- | :--- |
| **코딩 · 리팩토링 (SWE-bench)** | **Claude Opus · Sonnet 계열** | GPT-6 추론(Sol/Astra) 바짝 추격 | Claude는 파일 수십 개를 건드릴 때 지시 사항을 덜 어기고 기존 코드 스타일을 잘 유지함. Claude Code와 결합 시 체감 격차가 큼 |
| **수학 · 과학 · 복합 논리 (AIME/GPQA)** | **GPT-6 추론 / Gemini Pro / Claude Opus** (백중세) | 신버전 출시마다 1위 교체 | 복잡한 전략 수립·알고리즘 증명은 추론 전용 모델을 켤 때 비약적으로 정확해지며, 일반 경량 모델은 중간 계산을 건너뛰는 경향이 있음 |
| **장문 문서 · 멀티모달 (100만 토큰+)** | **Gemini Pro (영상·오디오) / Claude (PDF·코드)** | 3사 플래그십 모두 1M+ 지원 | 텍스트 PDF·법률 계약서의 미세한 조항 대조는 **Claude**가 꼼꼼하고, 1시간짜리 회의 녹음·유튜브 영상 자체를 통째로 넣는 건 **네이티브 멀티모달인 Gemini**가 압도적으로 편함 |
| **실시간 웹 리서치 · 팩트체크** | **Perplexity Deep Research** | ChatGPT / Gemini Deep Research | ChatGPT·Gemini도 웹 검색이 강해졌지만, 문장마다 원문 URL을 붙여주고 출처를 교차 검증하는 속도와 깔끔함은 Perplexity가 여전히 기준점 |
| **한국어 문체 · 자연스러움** | **Claude(문체 정교) · Gemini(자연스러운 구어)** | ChatGPT도 번역투 크게 감소 | 기획서·칼럼·이메일처럼 어조와 논리 흐름이 중요한 글은 **Claude** 선호도가 높고, 한국 로컬 고유명사·일상 표현 이해는 방대한 한국어 웹 데이터를 학습한 **Gemini**가 매끄러움 |

<Callout type="tip" title="같은 구독 안에서도 모델을 바꿔 써야 한도가 안 막힙니다">
  Claude에서 단순 오타 수정이나 짧은 번역까지 최고 사양인 <strong>Opus</strong>로 돌리면 5시간 한도가 1시간 만에 닳습니다. 일상 작업은 <strong>Sonnet / Flash / 표준 모델</strong>로 처리하고, 아키텍처 설계·복잡한 계약서 검토·어려운 디버깅에만 <strong>Opus / GPT-6 추론</strong>을 켜는 습관이 핵심입니다.

## 3. 한국 실결제가 · 사용량 리셋 · API 손익분기점

요금표의 `$20`만 보고 결제하면 놓치는 3가지 실질 비용 구조가 있습니다.

| 서비스 | 보급형 플랜 | 표준 주력 (PC 웹 / 모바일 앱스토어) | 상위 헤비 플랜 | 사용량 제한(Rate Limit) 체감 |
| :--- | :--- | :--- | :--- | :--- |
| **ChatGPT** | Go ($8 / 앱 ₩13,000) | **Plus** ($20 / 앱 ₩29,000) | Pro 100 ($100, ₩159,000) / Pro 200 (₩299,000) | 고급 추론·Deep Research는 5시간 및 주간 한도 적용. Go는 광고 노출 가능·고급 추론 제한 |
| **Claude** | 없음 (무료 Sonnet/Haiku) | **Pro** ($20, 연 $17 / 앱 약 ₩33,000) | Max ($100) / Ultra ($200) | **5시간 롤링 리셋**. 긴 채팅창에 파일 계속 누적 시 매 턴 재계산되어 조기 도달 |
| **Google AI** | AI Plus (구글 원 연계) | **Google AI Pro** ($20급 / 국내 스토리지 연계별 상이) | Ultra (월 ₩119,000~₩300,000대) | Gemini Pro + NotebookLM + Flow(Veo) + Google One 스토리지 통합 |
| **Perplexity** | 에듀 할인 ($10) | **Pro** ($20, 연 $200 / 앱 약 ₩33,000) | Max ($200 / 앱 ₩299,000) | Deep Research는 일·주간 전용 횟수 제한, 일반 Pro Search는 넉넉함 |

### 결제 전 따져봐야 할 비용 손익분기점 2가지
1. **PC 웹 직접 결제 vs 앱스토어 인앱결제:** Claude Pro와 Perplexity Pro를 아이폰 앱스토어로 결제하면 월 33,000원(연 약 39.6만 원)이지만, PC 브라우저 공식 사이트 연간 결제($200/년)를 쓰면 환율 감안 시 **연 5~8만 원 이상** 차이가 납니다. 웹에서 결제해도 모바일 앱에 로그인하면 유료 혜택이 그대로 연동됩니다.
2. **월 $20 구독 vs API 종량제:** 하루 10회 미만으로 짧은 질문·이메일 다듬기만 한다면 월 토큰 사용량이 100만 토큰도 안 됩니다. 이 경우 OpenAI/Anthropic/Gemini API 종량제(월 3,000~8,000원 수준)가 정액제보다 훨씬 쌉니다. 반대로 50쪽 PDF 요약·코딩 에이전트·심층 리서치를 매일 돌린다면 정액제가 API 대비 3~5배 이상 유리합니다.

## 4. 사용자 유형 6가지별 “이 사람에겐 딱 이것” 맞춤 추천

“무엇이 제일 좋나요?”보다 <strong>“내가 하루 중 가장 오래 붙잡고 있는 작업이 무엇인가?”</strong>로 골라야 중복 결제를 막을 수 있습니다.

### ① 백엔드 · 프론트엔드 · 1인 개발자 → **Claude Pro (월 $20, 연 $17)**
- **추천 이유:** SWE-bench 최상위권인 **Claude Sonnet/Opus**를 웹과 터미널(**Claude Code**)에서 동시에 쓸 수 있습니다. 긴 에러 로그를 던졌을 때 엉뚱한 라이브러리를 지어내는 빈도가 낮고, 리팩토링 시 기존 설계를 존중합니다.
- **이럴 땐 비추천:** 하루 종일 자율 에이전트를 돌리는데 5시간 리셋에 자꾸 걸린다면 Max($100)나 [Cursor·Copilot 하이브리드 조합](/posts/2026-ai-coding-tools-guide/)을 함께 고려해야 합니다.

### ② Gmail · 구글 드라이브 · 문서/강의 영상이 많은 직장인 → **Google AI Pro**
- **추천 이유:** 이미 Google One 클라우드를 쓰고 있다면 체감 추가 비용이 가장 낮습니다. 1시간짜리 회의 녹음이나 유튜브 강의 링크를 **Gemini Pro + NotebookLM**에 통째로 넣고 핵심만 뽑거나, Google Docs 안에서 바로 초안을 고치는 동선이 매끄럽습니다.
- **이럴 땐 비추천:** 회사 표준이 MS Office(엑셀·PPT)와 로컬 파일 위주라면 구글 앱 연동 이점이 크게 줄어듭니다.

### ③ 기획자 · 마케터 · 다양한 업무를 앱 하나로 처리하는 올라운더 → **ChatGPT Plus (월 $20)**
- **추천 이유:** 엑셀 CSV 파일을 올려 Python으로 바로 차트를 뽑거나, 출퇴근길에 **실시간 음성 모드**로 아이디어를 정리하고, 간단한 시안 이미지까지 한 앱에서 끝낼 수 있는 생태계 완성도가 가장 높습니다.
- **이럴 땐 비추천:** 장문 한국어 칼럼이나 보고서 특유의 매끄러운 문체가 최우선이라면 Claude 쪽 만족도가 더 높은 경우가 많습니다.

### ④ 대학원생 · 논문 연구원 · 투자/시장조사 실무자 → **Perplexity Pro (학생 $10 / 일반 $20)**
- **추천 이유:** 팩트체크가 생명인 작업에서는 일반 챗봇의 그럴듯한 거짓말(환각)을 걸러내는 시간이 더 듭니다. Perplexity는 모든 문장에 원문 링크를 달아주고, 같은 질문에 **Claude와 GPT 답변을 교차 비교**할 수 있습니다.
- **이럴 땐 비추천:** 긴 보고서를 여러 번 주고받으며 문단 단위로 다듬는 공동 집필 용도로는 Claude·ChatGPT보다 불편합니다.

### ⑤ 사내 기밀 문서 · 보안 코드 때문에 외부 전송이 금지된 경우 → **구독 대신 로컬 LLM(Ollama)**
- **추천 이유:** 아무리 좋은 유료 구독도 회사 보안 규정상 외부 서버로 데이터를 못 보내면 쓸 수 없습니다. 16GB~24GB 이상 메모리의 PC나 맥북이 있다면 [로컬 LLM(Ollama) 구축 가이드](/posts/2026-local-llm-ollama-setup-guide/)를 참고해 오프라인 환경으로 분리하는 것이 맞습니다.

### ⑥ 하루 5~10회 미만 가볍게 쓰는 라이트 유저 → **결제하지 마세요**
