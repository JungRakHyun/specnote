왜 단순 프롬프트 복붙은 자동화가 아닌지(자동화 3단계 성숙도), 무료 AI 엔진 3종 역할 분담, 실제 입력·출력 Before/After와 Google Apps Script 실행 코드까지 5가지 실전 세팅을 정리했습니다.

✓30초 핵심 요약

  • AI 업무 자동화는 1단계(매번 채팅창에 새로 치기) → 2단계(고정 템플릿 + 단축어·북마크 1클릭) → 3단계(구글 시트·폼 입력 시 Apps Script/Make가 자동 처리)로 나뉘며, 최소 2~3단계에 올려야 실제로 시간이 줄어듭니다.
  • 월 0원으로 가장 탄탄한 무료 스택은 '웹 무료 티어(긴 문서·이메일) + Google AI Studio 무료 API(시트 대량 분류) + Perplexity 무료(출처 검증 브리핑) + Make 무료(월 1,000오퍼레이션)' 조합입니다.
  • 무료 계정 업무 도입 시 가장 큰 리스크는 모델 학습 데이터 포함과 일일 호출 한도 초과이므로, 비식별화 규칙과 무료→유료 전환 기준선을 먼저 정해야 합니다.

“AI로 하루 2시간 아끼는 법” 같은 글을 읽고 따라 해봤는데 오히려 더 귀찮아진 경험이 있다면 원인은 하나입니다. 매번 챗봇 창을 열어 조건을 새로 타이핑하는 건 ‘자동화’가 아니라 ‘수동 작업’이기 때문입니다.

실제로 시간이 줄어들려면 입력(트리거) → AI 처리(고정 규칙) → 결과 저장(표·메일·슬랙) 중 최소 두 단계가 클릭 1번이나 자동 실행으로 묶여 있어야 합니다. 이 글에서는 무료 AI 자동화의 3단계 구조와 도구별 한도를 먼저 짚고, 오늘 바로 복사해 적용할 수 있는 5가지 실전 워크플로(실제 Before/After + 실행 코드 포함)를 정리했습니다.

1. 자동화 성숙도 3단계 & 월 0원 무료 스택 역할 분담

단계방식소요 시간 / 체감 효과적합한 업무
1단계 (수동)채팅창에 매번 프롬프트 새로 입력5~10분 소요, 결과 형식이 매번 달라 재편집 필요일회성 아이디어 브레인스토밍
2단계 (반자동)텍스트 대치 · Apple 단축어 · 북마크로 고정 템플릿 1클릭 호출30초~1분, 출력 형식이 항상 같아 바로 복붙 가능회의록 정리, 거절·일정 연기 메일, 아침 뉴스 브리핑
3단계 (자동)구글 시트 Apps Script · Make 무료가 입력 즉시 API 호출·기록0초(백그라운드 처리), 수십 건 일괄 처리 가능고객 문의 분류, 설문 요약, 견적 데이터 정규화

월 0원으로 조합하는 무료 엔진 4종 한도표 (2026년 11월 기준)

  • Claude / Gemini / ChatGPT 웹 무료 티어: 긴 텍스트 구조화·이메일 톤 교정 담당 (단, 하루 집중 사용 시 한도 도달 → 2~3개 교차 사용)
  • Google AI Studio 무료 Gemini API: 구글 시트(Apps Script)에서 셀 수십 개를 함수처럼 자동 분류할 때 사용 (분당·일일 무료 쿼터 제공)
  • Perplexity 무료 티어: 날짜와 원문 URL이 필수인 아침 업종 브리핑·팩트체크 전담
  • Make 무료(월 1,000오퍼레이션) / Zapier 무료(월 100태스크·2단계): 구글 폼 접수 → AI 요약 → 슬랙·이메일 알림 자동 연결

2. 바로 적용하는 5가지 실전 자동화 루틴 (Before/After + 코드)

루틴 ① 회의 녹취록 → 담당자별 액션 테이블 30초 변환 (2단계 반자동)

네이버 클로바노트 무료 시간이나 Google Meet 자막으로 뽑은 텍스트는 잡담과 말버릇이 섞여 바로 팀에 공유할 수 없습니다. 출력 컬럼을 못 박은 프롬프트를 macOS·Windows 텍스트 대치(;;회의록)나 노션 스니펫에 저장해 두세요.

실제 입력 예시 (어지러운 원본 메모):

김대리: 결제 페이지 로딩이 3초 넘게 걸리는데 배너 이미지 용량 때문인 듯요. 목요일까지 WebP로 바꿔볼게요.
박과장: 좋아요. 근데 금요일 마케팅 배너 교체 건은 디자인팀 시안이 아직 안 와서 보류해야 할 것 같습니다.
이팀장: 그럼 배너 건은 다음 주 화요일에 다시 보고, 김대리님은 목요일 오후 3시에 테스트 결과 공유해 주세요.

고정 템플릿 (;;회의록으로 호출):

아래 회의 메모에서 잡담을 제거하고 다음 3개 블록만 출력해 줘. 원문에 없는 내용은 절대 추측하지 말고 '미정'으로 적어.
1) 확정 사항 (불릿 최대 3줄)
2) 액션 아이템 표 (컬럼: 담당자 | 할 일 | 마감일 | 상태)
3) 보류·리스크 이슈 (1줄)

실제 출력 결과 (그대로 슬랙·노션에 붙여넣기):

담당자할 일마감일상태
김대리결제 페이지 이미지 WebP 변환 및 테스트 결과 공유목요일 15:00진행 예정
박과장마케팅 배너 교체 건 디자인팀 시안 대기다음 주 화요일 재논의보류

루틴 ② 구글 시트 문의 내역 → 카테고리·긴급도 자동 분류 (3단계 Apps Script)

구글 폼이나 고객 문의가 하루 20~50건씩 시트에 쌓일 때 사람이 일일이 읽고 분류하지 마세요. 구글 시트 상단 확장 프로그램 → Apps Script에 아래 코드를 넣고, 프로젝트 설정 → 스크립트 속성에 GEMINI_API_KEY를 저장하면 시트 B2 셀에 =CLASSIFY_INQUIRY(A2)만 적고 아래로 드래그해 수십 건을 한 번에 분류할 수 있습니다.

function CLASSIFY_INQUIRY(text) {
  if (!text) return "";
  const apiKey = PropertiesService.getScriptProperties().getProperty("GEMINI_API_KEY");
  const url = "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=" + apiKey;
  const payload = {
    contents: [{
      parts: [{
        text: "다음 문의를 [결제/환불, 기술오류, 제휴문의, 기타] 중 하나와 [긴급/보통/낮음]으로만 답해. 출력 형식: 카테고리 | 긴급도\n문의: " + text
      }]
    }]
  };
  const res = UrlFetchApp.fetch(url, {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify(payload)
  });
  const json = JSON.parse(res.getContentText());
  return json.candidates[0].content.parts[0].text.trim();
}
  • 보안 주의: API 키를 코드 안에 직접 문자열로 적으면 시트를 공유할 때 키가 그대로 노출됩니다. 반드시 PropertiesService 스크립트 속성에 분리 보관하세요.

루틴 ③ 까다로운 거절·일정 연기 메일 → 2버전 10초 초안 (2단계 반자동)

이메일에서 시간이 걸리는 이유는 어휘력이 아니라 수신자 직급·관계에 맞는 수위 조절입니다. 사실 3줄 + 수신자 성향 + 금지 표현 3요소를 고정해 Apple 단축어(Shortcuts)나 텍스트 대치에 넣어두세요.

[사실] 1) 납품 3일 연기 필요(11/28 → 12/1) 2) 사유: PG사 결제 예외 테스트 보완 3) 보완책: 최종 검수 리포트 추가 제공
[수신자] 외부 클라이언트 대기업 담당자 (격식·명확성 중시)
[요청] 변명처럼 보이지 않으면서 신뢰를 주는 '간결형(5줄 이내)'과 '정중형' 2가지 이메일 초안 작성
[금지] "심심한 사과", "최선을 다하겠습니다" 같은 상투적 표현 제외

루틴 ④ 매일 아침 5분 업종 브리핑 → 출처 URL 강제 검증 (2단계 북마크)

일반 챗봇에 “오늘 업계 뉴스 알려줘”라고 물으면 3달 전 기사를 오늘 뉴스처럼 섞어 말할 때가 많습니다. 실시간 출처 검색에 특화된 Perplexity 무료 티어에 아래 프롬프트를 저장해 두고 매일 아침 클릭 한 번으로 실행하세요.

최근 72시간 내 발표된 국내외 [내 업종: 예) 생성형 AI 요금제 / 국내 이커머스 물류] 핵심 뉴스 5건만 표로 정리해 줘.
필수 조건: 1) 언론사·공식 블로그 원문 URL 링크 포함 2) 발행 날짜 명시 3) 우리 실무 영향 1줄 요약. 출처가 불분명한 루머 제외.

루틴 ⑤ 평일 1줄 메모 → 금요일 주간 보고서 3분 완성

금요일 오후 4시에 기억을 더듬지 말고 월~금 동안 노션·메모장 한 페이지에 11/24 결제 API 타임아웃 원인 수정 (응답시간 2.4s → 0.6s)처럼 결과 수치 1줄씩만 던져둡니다. 금요일에 통째로 복사해 금주 완료(수치 포함) / 지연·리스크(원인+대응) / 차주 Top 3 포맷으로 변환하되, “원문에 없는 성과 수치는 절대 지어내지 말 것” 조건을 붙여 환각을 차단하세요.

3. 직군별 1주차 도입 순서 & 무료 자동화의 한계

  • CS · 영업 · 운영 실무자: 루틴 ②(시트 자동 분류) + 루틴 ③(메일 2버전)부터 붙이면 일일 반복 시간이 가장 크게 줄어듭니다.
  • 기획 · 마케팅 · 리서치: 루틴 ④(아침 72시간 브리핑) + 루틴 ①(회의록 액션 테이블) 조합이 즉효성이 큽니다.
  • 1인 사업자 · 개발자: 위 무료 루틴에 더해 반복 웹앱·사내 도구가 필요하다면 바이브 코딩 입문 로드맵으로 직접 미니 툴을 띄우는 편이 확장성이 좋습니다.
무료 구성에서 막히는 상황원인현실적인 다음 단계
하루 30~50건 이상 시트·문서 대량 자동 처리무료 API 분당(RPM)·일일 쿼터 초과유료 API 종량제(월 수천 원) 또는 AI 유료 구독 비교 참고
사내 보안 문서·계약서·고객 개인정보 처리외부 서버 전송 자체가 사내 규정 위반오프라인에서 돌아가는 로컬 LLM(Ollama) 구축
3단계 이상 분기·조건이 복잡한 앱 연동Zapier 무료(월 100태스크·2단계) 한계Make 무료(월 1,000오퍼레이션) 또는 자체 호스팅 n8n
무료 계정 업무 도입 전 필수 보안 수칙 2가지
  1. ChatGPT·Claude·Gemini 무료 계정의 설정에서 “모델 학습에 내 대화 사용” 옵션을 먼저 끄세요. 2) 고객 실명·전화번호·계좌·내부 매출액은 붙여넣기 전에 A사 / 담당자1 / OO원으로 치환하는 습관이 안전합니다.

자주 묻는 질문 (FAQ)

Q. 코딩을 전혀 모르는 비개발자 직장인도 Google Apps Script 코드를 붙일 수 있나요?▾

가능합니다. 구글 시트 상단 메뉴의 '확장 프로그램 → Apps Script'를 열어 본문의 코드를 그대로 붙여넣고, 프로젝트 설정의 스크립트 속성에 무료 Gemini API 키만 넣으면 끝입니다. 에러가 나면 메시지 그대로 Claude나 ChatGPT에 붙여넣어 수정본을 받으면 10분 안에 동작합니다.

Q. 무료 AI에 사내 회의록이나 고객 문의를 넣어도 보안상 괜찮나요?▾

아니요, 기본 설정 그대로 넣으면 보안 위험이 큽니다. 개인 무료 계정은 기본값으로 대화가 모델 개선 학습에 쓰일 수 있으므로, 반드시 설정에서 '모델 학습에 데이터 사용' 옵션을 끄고 고객 실명·연락처·계약 금액은 입력 전 'A사', '담당자1', 'X원'으로 치환(비식별화)해야 합니다. 아예 외부 전송이 금지된 회사라면 로컬 LLM(Ollama)을 써야 합니다.

Q. 무료 툴로 쓰다가 어느 시점에 유료 구독으로 넘어가는 게 본전을 뽑나요?▾

하루에 20쪽 이상 PDF나 30분 이상 녹취록을 3건 넘게 처리하거나, 무료 일일 한도에 걸려 작업이 주 3회 이상 끊기기 시작하면 월 2~3만 원대 유료 플랜 하나를 결제하는 편이 시간당 인건비 대비 훨씬 남습니다.
